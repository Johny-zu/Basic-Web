# Repositorio para paginas web basicas
En este repositorio se practicara los fundamentos de paginas web, funcionamientos, implementaciones con JS, CSS y HTML, con esto se estara dando una base de conocimientos para la pruebas posteriores para nuevos proyectos

## Informacion basica 
En el siguiente encarpetado se veran ejercicios basicos para la adaptacion del html y css basico
- Etiquetas basicas
- Atributos
- capturas por usuario
- formularios

## Informacion integrada
En el siguiente encarpetado se veran mas cosas de la web pero con la integracion de JS para darle funcionalida a las paginas
Se ven aqui 3 carpetas con funcionalidades para los inputs, toma de valores, la revision de los value y ademas el comportamiento de la interaccion con los scripts, con esto se comenzara con unos ejemplos mas como el de tarjeta con el fin de dar con la posibilidad de uso de frameworks
